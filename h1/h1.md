# H1 - Optimización del registro y búsqueda de Kardex de pacientes

El proceso seleccionado es el registro, actualización y búsqueda de Kardex de pacientes.
Actualmente, la información se administra mediante registros y archivos que requieren revisión manual.
El personal administrativo y médico es quien realiza y utiliza este procedimiento.
Se maneja un volumen aproximado de entre 300 y 350 registros de pacientes.
Cuando se necesita localizar un Kardex, el personal tarda aproximadamente entre 5 y 10 minutos.
Este tiempo puede aumentar cuando existen varios registros o información difícil de localizar.
El proceso manual puede ocasionar demoras, duplicación de información y errores de registro.
La búsqueda de datos representa una dificultad cuando se necesita acceder rápidamente al historial de un paciente.
El objetivo es optimizar este procedimiento mediante el uso de algoritmos de búsqueda y organización.
Se pretende reducir el tiempo necesario para encontrar un registro específico.
También se busca mejorar la organización y recuperación de la información almacenada.
La optimización permitirá comparar el tiempo de búsqueda actual con el tiempo obtenido mediante el algoritmo.
El proyecto se desarrollará durante este mes como parte de las prácticas de la fase 1.
